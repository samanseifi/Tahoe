# 3D variants — bar and plate

Young-Laplace only.  Extension of the 2D paper setup to 3D.  Both XMLs
use the staggered explicit solver path: a `<diffusion>` Poisson pass
for Ψ followed by `<updated_lagrangian_Q1P0_3D_surface>` mechanics on
the central-difference integrator.

## Geometries

* [../meshes/bar_3D.geom](../meshes/bar_3D.geom) — 80 × 4 × 4 hex8 bar
  (extrusion of the 2D paper geometry along z).  Generated by
  [`../scripts/generate_bar_3D.py`](../scripts/generate_bar_3D.py)
  with default flags.

* [../meshes/plate_3D.geom](../meshes/plate_3D.geom) — 40 × 4 × 40 hex8
  plate; same script with `--Lx 40 --Lz 40 --Nx 40 --Nz 40`.

## XMLs

| File                                                            | Domain |
| ----------------------------------------------------------------| ------ |
| [staggered_explicit_3D.xml](staggered_explicit_3D.xml)           | bar (Lz = 4) |
| [staggered_explicit_plate_3D.xml](staggered_explicit_plate_3D.xml) | plate (Lx = Lz = 40) |

Both apply the surface tension on the top face (`side_set_ID="1"`,
y = H).  Front and back faces (z = 0 and z = Lz) are taken as the
roller pair in the 3D bar; the plate uses periodic-ish BCs (see
the XML for exact node sets).

## GM status

3D Gurtin-Murdoch is blocked until `SimoQ1P0_3D_Surface` gains an

## Running

```bash
cd 3D_young_laplace_experiments && ../../../build/bin/tahoe -f staggered_explicit_3D.xml
```

These runs are 10-30× slower than the 2D paper cases.  Expect minutes
to hours per sweep point on a workstation; consider MUMPS in parallel
for the diffusion pass.
