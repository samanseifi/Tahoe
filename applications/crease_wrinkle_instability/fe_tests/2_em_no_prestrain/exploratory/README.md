# 2D paper replication — Seifi & Park 2016 IJSS section 4.2

Young-Laplace surface tension only.  Geometry: 80 × 4 unit-square
quad4 strip from [../meshes/bar_2D.geom](../meshes/bar_2D.geom)
(generated by [../scripts/generate_bar_2D.py](../scripts/generate_bar_2D.py)).

BCs: bottom clamped (NS 1), side rollers (NS 3 / NS 4), top free with
Ψ = V(t).  Side set 1 carries the Young-Laplace force.

## XMLs

| File                                                | Solver                                 | When to use |
| --------------------------------------------------- | -------------------------------------- | ----------- |
| [monolithic_2D.xml](monolithic_2D.xml)               | coupled element + nonlinear-HHT        | reference implicit baseline (single coupled element) |
| [monolithic_static_2D.xml](monolithic_static_2D.xml) | coupled element + static               | quasi-static reference; convergence stalls near V_crit (see #53) |
| [staggered_2D.xml](staggered_2D.xml)                 | diffusion + Q1P0_surface (HHT implicit)| compare against monolithic; slow at threshold |
| [staggered_explicit_2D.xml](staggered_explicit_2D.xml) | diffusion + Q1P0_surface (explicit)  | **recommended** for sweeping γ — no Newton stalls |
| [staggered_static_2D.xml](staggered_static_2D.xml)   | diffusion + Q1P0_surface (static)     | quiet equilibrium probe; not robust past V_crit |

The corresponding GM (`E_s ≠ 0`) variants live in
[../GM_experiments/](../GM_experiments/).

## Reproducing paper figures

Edit `gamma` in either staggered or monolithic XML to step through the
γ̄ table in the top-level [README](../README.md).  Plot `max|D_Y|` on
the top edge vs V to find V_crit per γ; compare against Wang-Zhao.

## Running

```bash
cd 2D_young_laplace_experiments && ../../../build/bin/tahoe -f staggered_explicit_2D.xml
```
